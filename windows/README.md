# Nova Parcel · Windows

Windows-версія віджета Нової пошти з оформленням macOS-версії: світлий фон, червоні акценти, картки з описами та індикатором доставки. Окреме компактне вікно на Electron; це не розширення системної панелі «Віджети» Windows.

## Встановлення

Підтримується **Windows 10/11, x64**.

1. Відкрийте [реліз Windows 0.2.0](https://github.com/FakerFox/nova-parcel/releases/tag/v0.2.0-windows).
2. У розділі **Assets** завантажте **Nova-Parcel-Setup-0.2.0-x64.exe**.
3. Запустіть інсталятор. Він працює для поточного користувача, створює ярлики на робочому столі та в меню «Пуск».
4. Запустіть Nova Parcel, натисніть **«Увійти за номером телефону»** й завершіть вхід в офіційному кабінеті Нової пошти.
5. Увімкніть сповіщення у віджеті. Їх також мають дозволяти налаштування Windows; режим «Не турбувати» може приховувати банери.

Інсталятор поки не має цифрового підпису видавця. Windows може показати повідомлення про невідомого видавця. Поруч з інсталятором зберігається контрольна сума SHA-256.

Проміжні збірки також доступні в [GitHub Actions](https://github.com/FakerFox/nova-parcel/actions/workflows/windows.yml): відкрийте успішний запуск → **Artifacts** → **Nova-Parcel-Windows-x64**. Для завантаження артефактів потрібен вхід до GitHub; вони зберігаються 30 днів.

## Що працює

- Вхід через офіційний вебкабінет, відновлення сесії після перезапуску.
- Вхідні й вихідні посилки; опис відправлення замість загальної назви. Повний опис — при наведенні на заголовок.
- Оновлення приблизно раз на 5 хвилин, перевірка після пробудження, ручне оновлення й поступове збільшення інтервалу при помилках.
- Сповіщення Windows при зміні коду або тексту статусу. Перша синхронізація, додавання посилки та уточнення опису проходять без сповіщень.
- Додавання ТТН вручну, копіювання номера натисканням, фільтр отриманих посилок.
- Закріплення поверх вікон, збереження положення та розміру, автозапуск за бажанням.
- Хрестик ховає вікно у трей. Натисніть коробку біля годинника або відкрийте ярлик ще раз, щоб повернути вікно. Для завершення перевірок оберіть **«Завершити Nova Parcel»** у меню коробки.

## Збірка

Потрібні Windows x64 і **Node.js 24 LTS**. Команди виконуються в цій папці:

```powershell
npm ci
npm test
npm start
```

Зібрати інсталятор:

```powershell
npm run dist:win
node scripts/packaged-smoke.cjs
```

Результат: `dist/Nova-Parcel-Setup-0.2.0-x64.exe`. Збирання інсталятора виконується на Windows; macOS-версія в корені репозиторію залишається окремою нативною Swift-збіркою.

`npm run demo` відкриває вигадані посилки без мережі в окремому тимчасовому профілі. `npm run preview` запускає локальний макет для перевірки оформлення у браузері. Цей макет не входить до інсталятора і не підключається до акаунта.

## Дані й авторизація

Сесія Нової пошти зберігається в окремому профілі Chromium цього застосунку. Нативний код не отримує токени, SMS-коди чи паролі: спільний адаптер `../Resources/Bridge.js` виконується тільки на `https://new.novaposhta.ua` і повертає мінімальний список відправлень. Ця інтеграція залежить від формату вебкабінету; це не офіційний партнерський OAuth-клієнт.

Локальні дані — у `%APPDATA%\Nova Parcel`: `parcels.json`, `preferences.json` і браузерна сесія. «Вийти» прибирає список посилок і сесію цього застосунку; інші входи до Нової пошти не відкликаються. Windows-версія потребує власного входу: сесія з Mac не переноситься.

Офіційна сторінка входу працює без доступу до Node.js і без нативного IPC. Локальний інтерфейс ізольований, не виконує мережевих запитів і відображає описи відправлень як текст.

## Перевірки

`npm test` перевіряє переходи статусів, описи, відсутність дублів сповіщень, відновлення стану, зміну акаунта, вихід під час запиту, повторні спроби, перевірку ТТН і межі доступу до нативних функцій. Додатково запускаються спільні перевірки адаптера Нової пошти.

GitHub Actions запускає тести на Windows, перевіряє відкриття Electron-вікна та його ізоляцію, збирає NSIS-інсталятор і запускає вже упакований застосунок із вигаданими посилками. Перевірка справжнього SMS-входу й доставки сповіщень на особистому Windows-комп’ютері потребує ручного проходження після встановлення.

Технічні джерела: [Electron security](https://www.electronjs.org/docs/latest/tutorial/security), [сповіщення Windows](https://www.electronjs.org/docs/latest/tutorial/notifications), [NSIS installer](https://www.electron.build/nsis.html).
