# Nova Parcel · macOS

Локальний експериментальний трекер Нової пошти українською. Працює на Apple Silicon із macOS 14 або новішою.

## Збірка з вихідних файлів

Потрібні Xcode / Command Line Tools; для тестів адаптера — Node.js 18 або новіший. Сторонніх залежностей немає.

```sh
git clone https://github.com/FakerFox/nova-parcel.git
cd nova-parcel
./build.sh
./test.sh
open "dist/Nova Parcel.app"
```

Збірка створює застосунок у `dist/`, а тимчасові файли — у `.build/`. Обидві папки виключені з Git.

## Запуск

1. Відкрийте зібраний **dist/Nova Parcel.app** або вже встановлену копію **Nova Parcel.app**. За бажанням перенесіть застосунок до «Програм»; це також рекомендовано для автозапуску.
2. Натисніть **«Увійти за номером телефону»**. Відкриється офіційний вебкабінет Нової пошти у вікні застосунку.
3. Введіть телефон і пройдіть підтвердження на сайті. Спосіб підтвердження визначає Нова пошта; він може включати код або додаткову перевірку. Застосунок сам не надсилає SMS і не обходить перевірки.
4. Після успішної синхронізації застосунок покаже вхідні й вихідні посилки за останні три місяці. Старіші вже відстежувані посилки залишаться у списку.
5. Натисніть **«Увімкнути сповіщення про зміни»** і дозвольте сповіщення у macOS. Перевірити їх можна в налаштуваннях віджета.

Можна також додати ТТН вручну. Якщо публічний API не повертає її статус, увійдіть до акаунта.

## Поведінка

- Перевірка приблизно кожні 5 хвилин, поки Mac не спить. Після помилок інтервал поступово збільшується до години; кнопка оновлення перевіряє одразу.
- Перша синхронізація не створює сповіщень. Повідомлення з’являється при зміні коду або тексту статусу вже відомої посилки.
- Версія 0.1.2: заголовки показують опис відправлення з Нової пошти. Повний опис доступний при наведенні; якщо сервіс тимчасово не повертає опис, зберігається попередній. Саме уточнення опису не створює сповіщення про зміну статусу.
- Закриття вікна залишає застосунок у рядку меню. Команда «Завершити Nova Parcel» зупиняє перевірки.
- Версія 0.1.1: коробка отримує початкове місце справа у смузі меню; вибране положення зберігається після перезапуску. Ця початкова позиція використовує внутрішню настройку AppKit, тому абсолютна видимість при переповненні смуги не гарантується.
- Значок шпильки закріплює вікно поверх інших. Положення й розмір вікна зберігаються.
- Отримані посилки ховаються з активного списку. Натисніть «Усі посилки», щоб побачити їх.
- На сповіщення також впливають налаштування macOS та режим «Зосередження».

## Межі цієї версії

Це **компактний віджет-вікно та застосунок у рядку меню**, а не розширення WidgetKit у системній галереї віджетів. Для повноцінної версії WidgetKit із загальними даними потрібні окреме розширення, підпис і налаштування App Group. На цьому Mac на момент розробки не було дійсного сертифіката Apple Developer.

Вхід за телефоном використовує офіційний вебкабінет у WebKit. Після входу локальний адаптер читає список посилок через ті самі методи, які використовує вебкабінет. Це **не документована партнерська інтеграція OAuth** і може потребувати оновлення, якщо Нова пошта змінить сайт або формат відповіді. Реєстрація власного OAuth-клієнта тут не виконується. Старий спосіб входу без OAuth-сесії не підтримується.

Перевірено на цьому Mac: вхід користувача через офіційну форму з кодом, отримання двох реальних активних посилок, повторна синхронізація та відновлення сесії після перезапуску, доставка тестового сповіщення в Центр сповіщень macOS, збірка та 36 автоматичних перевірок. Справжньої зміни статусу під час розробки ще не спостерігали; порівняння статусів і відсутність повторних сповіщень перевірено на тестових даних.

Застосунок локально підписаний ad hoc, без нотаризації Apple. Збірка призначена для цього Mac; це ще не реліз для розповсюдження.

## Дані та вихід

- Немає власного сервера чи аналітики. Запити про посилки йдуть до `api.novaposhta.ua`; сторінка входу завантажує ресурси офіційного сайту та його постачальників.
- Cookies та OAuth-сесія залишаються у сховищі WebKit для офіційного сайту. Нативна частина не копіює токени, паролі чи коди підтвердження у файли налаштувань або журнали.
- Локальний список містить ТТН, статус, коротку назву, місце доставки й час перевірки. Файл: `~/Library/Application Support/NovaParcel/parcels.json`, доступ лише поточному користувачу.
- «Вийти» очищує локальну сесію WebKit, список посилок і сповіщення цього застосунку. Це не відкликає інші сесії на стороні Нової пошти.
- Зміна акаунта створює новий початковий стан, щоб не порівнювати посилки різних акаунтів.

## Розробка

```sh
./build.sh
./test.sh
```

Шляхи збірки можна змінити через `NOVA_APP_DIR` та `NOVA_BUILD_DIR`. Параметр застосунку `--demo` показує вигадані дані без мережі та без запису посилок; `--background` ховає головне вікно при запуску.
